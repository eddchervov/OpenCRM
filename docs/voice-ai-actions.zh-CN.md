# 语音助手操作

[English](voice-ai-actions.md) | [Русский](voice-ai-actions.ru.md) | **简体中文**

> 本页为机器译稿。涉及部署、接口或数据变更时，请同时核对英文或俄文原文。

由75个可执行命令组成的完整目录通过 CRM 工作空间中的“ QQ ” (可用命令) 打开 `#assistant` 节。  每个短语使用一个命令 。 助手首先通过普通的API读取对象并显示建议的修改;写入在确认后发生.  删除和取消需要额外的复选框. 选择多个匹配时的特定工作顺序; 指定工作项目共享名称时的行号。

| 区域 | 可用行动 |
| --- | --- |
| 工作命令 | 建立已完成的访问或初步任命;接受、启动、重新安排、更改字段/日期、折扣/费用、取消/删除、返回计划/进行中、完成、标记准备、移交和根据本组织目前的工作流程撤销移交。 |
| 工作项目 | 添加;更改名称/价格/数量/说明/VAT/指定人;删除一行;替换列表。  其他线条,材料,和地被保存. |
| 付款 | 记录个人付款和付款人;有正当理由取消具体付款。  没有真正的钱被收取。 |
| 摄入量 | 里程、提供的物品、损坏、票据、雇员和工作工位。 |
| 车辆和客户 | 创建、查找、更新和链接车辆与客户; 归档/更新车辆; 客户详情、电话、标签和票据。 |
| 目录 | 查看,创建,更新并删除条目和工作湾;通过活动旗子存档;明确服务捆绑组成. |
| 人员与轮班 | 雇员记录、停用、与现有成员的联系而不改变其作用;创建/更新/取消班次、公布和复制一周。 |
| 库存 | 库存水平、收据、注销、数量/费用调整、升/毫升和克/克换算。 |
| 缺陷和阅读 | 创建,更新,关闭,并删除缺陷;添加或删除车辆读取. |
| 执行 | 启动,暂停,恢复,并完成一项操作;调整分钟,说明理由;文本报告,建议书决定;重大消耗和全部返回一项操作. |
| 读取操作 | 某一期间的附表和财务报告。 |
