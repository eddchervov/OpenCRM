# Организации в desktop-админке opencrm.example.invalid

Список «Организации» содержит организации любых владельцев, включая прежние организации скрытого автопарка. Поиск по организации и владельцу, карточка, статистика, состав участников и аудит сохраняются. Чтение требует `Admin.Users.View`, изменение статуса — дополнительно `Admin.Users.Manage`; системный администратор использует действующие серверные правила доступа.

В карточке доступны «Принудительно архивировать» и «Восстановить из архива». Действие требует причины до 2000 символов и отдельной отметки подтверждения. Перед выполнением показываются название, владелец и ID выбранной организации. Удалённые организации изменять нельзя; восстановление доступно только из архива.

Административная архивация работает при выключенном пользовательском `Organizations:ArchivingEnabled`, без членства администратора в организации и без подмены владельца. Пользовательский запрет сохраняется. Сервер выполняет операцию под существующей блокировкой организации в транзакции и записывает фактического администратора и причину в события `organization.admin_archived` / `organization.admin_restored`.

Архив закрывает рабочий доступ участникам. Действует прежний срок хранения: через 30 дней штатная очистка помечает организацию удалённой. До этого её можно восстановить с сохранением данных и действующих условий подписки. Архивная организация продолжает занимать слот создания организации своего типа.

API: `POST /api/v1/admin/organizations/{id}/archive` и `/restore`, тело `{ "reason": "..." }`, успешный ответ `{ "message": "..." }`. Пустая или слишком длинная причина отклоняется; недопустимый текущий статус возвращает конфликт. При потере ответа desktop не повторяет запись и блокирует новые изменения статуса до успешного обновления карточки.

Публикация desktop-клиента и публикация серверных API — разные операции. Для работы новых действий сервер должен содержать эту актуализацию; копирование desktop-сборки не обновляет сервер.

## Веб-список и Free/PRO

Веб-админка дополнена отдельным списком организаций, поиском и серверной пагинацией, мобильными карточками и переходом к организациям владельца. В обоих клиентах активные детейлинг и СТО без подписки показывают бессрочный Free; архивные и удалённые организации сохраняют фактическое состояние. Серверные карточки возвращают имя системного Free без искусственной даты окончания. Подробности управления тарифом — в [описании подписок](admin-subscriptions.md).
