# Команды голосового пилота opencrm.example.invalid

[English](voice-ai-actions.md) | **Русский**

Полный каталог из 75 исполняемых команд открывается кнопкой «Доступные команды» в модальном окне `/assistant/{organizationId}` (локальный вход — `/ai-pilot`). Одна команда за фразу. Сначала помощник читает объект через обычное API и показывает изменения; запись выполняется после подтверждения. Удаление и отмена требуют дополнительную галочку. При нескольких заказах нужно выбрать конкретный; для одинаковых работ — назвать номер строки.

| Область | Доступные действия |
| --- | --- |
| Заказ | Создать выполненный визит или предварительную запись, принять, начать, перенести, изменить поля и даты, скидку/себестоимость, отменить/удалить, вернуть в план или работу, завершить, отметить готовность, выдать и отменить выдачу — согласно текущему процессу организации. |
| Работы | Добавить, изменить название/цену/количество/описание/НДС/исполнителя, удалить строку, заменить список. Остальные строки, материалы и поля сохраняются. |
| Оплаты | Учесть отдельный платёж и плательщика, отменить конкретный платёж с причиной. Реальные деньги не списываются. |
| Приёмка | Пробег, комплектность, повреждения, заметки, сотрудник и пост. |
| Автомобили и клиенты | Создать, найти и изменить, связать авто с клиентом; архивировать/восстановить авто; данные клиента, телефон, теги, примечание. |
| Справочники | Просмотр, создание, изменение и удаление позиций и постов; архив через активность; явный состав наборов услуг. |
| Люди и смены | Карточки сотрудников, деактивация, связь с уже существующим участником без смены роли; создание/изменение/отмена смен, публикация и копирование недели. |
| Склад | Остатки, приход, списание, корректировка количества и себестоимости, перевод л/мл и кг/г. |
| Неисправности и показания | Создать, изменить, закрыть и удалить неисправность; добавить или удалить показание автомобиля. |
| Исполнение | Начать, приостановить, продолжить и завершить операцию; исправить минуты с причиной; текстовый отчёт, решение по предложению; расход и полный возврат материала операции. |
| Чтение | Расписание и финансовый отчёт за период. |

## Фразы для проверки

- «Добавь в А123ВС154 работу замена фильтра за пятьсот рублей».
- «Измени цену замены фильтра в А123ВС154 на семьсот рублей».
- «Удали работу замена фильтра из А123ВС154».
- «Перенеси А123ВС154 на послезавтра с двенадцати до часа дня».
- «Для А123ВС154 измени комментарий на ожидаем запчасти».
- «Для А123ВС154 установи скидку сто рублей».
- «Прими оплату семьсот рублей наличными за А123ВС154».
- «Отмени оплату семьсот рублей за А123ВС154, причина — ошибочная запись».
- «Создай клиента Иван Тестовый с телефоном 79001234567».
- «Привяжи А123ВС154 к клиенту Иван Тестовый».
- «Измени телефон клиента Иван Тестовый на 79001234568».
- «Добавь сотрудника Сергей».
- «Назначь Сергея на заказ А123ВС154».
- «Создай пост Бокс номер два».
- «Назначь пост Бокс номер два для А123ВС154».
- «Создай смену Сергею завтра с девяти до восемнадцати».
- «Прими на склад пять литров масла по двести рублей за литр».
- «Поставь замену масла А123ВС154 на паузу, причина — ждём фильтр».
- «Продолжи замену масла А123ВС154».
- «Добавь пятнадцать минут к замене масла А123ВС154, причина — забыл включить таймер».
- «Покажи финансы с первого по двадцать шестое октября».

«Сделали» создаёт отдельный выполненный визит; «закончили» завершает найденный заказ. До создания записи помощник уточняет хотя бы одну работу. Новые работы сверяются со справочником: точное совпадение связывается с услугой, отсутствие совпадений даёт произвольную строку, похожие названия требуют выбора. Для плановой записи неназванная цена берётся из выбранной активной услуги справочника. Если цены нет, помощник спрашивает стоимость каждой такой работы; ответ «пока неизвестно» оставляет её пустой до последующего уточнения. Названная сотрудником цена, включая нулевую, имеет приоритет. Сумма одной работы может быть задана общей стоимостью; общую сумму нескольких работ помощник не распределяет. Выбор услуги, дата, время и пост сохраняются при ответах о цене; изменившаяся справочная цена требует повторной проверки черновика. Последнюю работу удалить нельзя; сначала добавьте заменяющую. Для завершения нужны цены и выполненные операции согласно обычным правилам CRM. Неназванные поля не очищаются.

Код, SQL, URL API, тарифы и роли моделью не управляются. Файлы/фото и внешние рассылки в пилот не подключены. Абсолютные прошлые интервалы пока не редактируются; есть текущий таймер и корректировка минут. Подробности изоляции, бюджетов и проверок — в [описании помощника](ai-assistant.ru.md).
