# UML-диаграммы

[English](README.md) | **Русский**

Исходные диаграммы PlantUML иллюстрируют модель приложения и взаимодействия. Это архитектурные иллюстрации; перед изменением контрактов сверяйтесь с актуальным кодом и [описанием архитектуры](../architecture-current.ru.md).

- [Регистрация и аутентификация](authentication-sequence.ru.puml).
- [Предметная модель](domain-model.ru.puml).
- [Создание обслуживания](maintenance-sequence.ru.puml).
- [Оплата и активация подписки](payment-sequence.ru.puml).
- [Зависимости проектов](project-components.ru.puml).
- [Общая архитектура](system-architecture.ru.puml).
- [Доступ к рабочему пространству](workspace-access-sequence.ru.puml).

Для просмотра откройте исходник в редакторе с поддержкой PlantUML. Английская и русская версии используют одинаковые идентификаторы компонентов и связи.
