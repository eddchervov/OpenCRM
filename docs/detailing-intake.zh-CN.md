## 检查图版本

检查使用固定的图表版本;公布的版本是 `sedan-v1`.  它由下列组成: `front.png`, `rear.png`, `left.png`, `right.png`,以及 `diagram.json` 内 `packages/workspace/src/assets/intake/sedan-v1/`.

 一个绘画和几何版本被固定在全程检查中 `Maintenance.IntakeDiagramVersion`.  在第一次保存前,Get建议不写入数据库的当前版本. 保存一个标记必须包括显示给用户的图的版本:在持有工作命令锁时,服务器会给一个支持的版本打针,或者拒绝与已经被钉住的版本不匹配(409). 首个保存收录文本也给当前版本打上针. 以后编辑并删除所有标记不会更改;一个数据库触发器阻止了被绑定值的更改或清除.

移动中包含版本字段、回填兼容的现有录入记录以及保护被绑定版本的触发器 `20261024101148_AddMaintenanceIntakeDamages`.

版本支持发射后的未来变化:如果检查已经保存,一幅新的绘图或几何获得一个新的标识符和单独的资产. 客户端和PDF渲染器仍可使用旧版本的资产。  现在还没有更早的版本。 未知版本从未被当前版本所取代:客户端保留对文本列表的访问并禁用坐标编辑,而PDF生成返回出错. 与不同的图相冲突需要重新装入检查并再次选择点.

减少合并迁移可以消除其表格、版本字段、触发器和由它迁移的数据。 数据库没有回滚;回滚图像是为了保存新的计划而设计的.  在分别决定降级计划之前,需要核查的备份/出口。

## 图表资产和支票

 第一版中的每个视图都有一个透明的1619×971画布.  在浏览器中,它占据了完整的坐标区域,没有背景变化或裁剪相邻的视图. 框架被绘制为内置阴影,不会缩小图像区域. 光和暗的主题使用相同的像素;一个过滤器改变外观的外观颜色而不移动.

`diagram.json` 定义版本,维度,文件名,以及 SHA-256. 客户端和PDF使用相同的资产和清单. PDF 生成验证加载时的校验和尺寸. 测试所有四个图像,几何,以及精确的相对坐标,包括边缘位置的针头校验和.  如果图像不可用,则禁用点选择并显示重试。 未知版本不为当前版本所取代.

原始合并工作表保存在Git at `scripts/assets/intake-body-projections.png` 只能复制资产产生。 `dotnet run --file scripts/build-intake-projections.cs -- <repository-root>` 校验出源SHA-256,用近邻缩放法将取出4个等相画布,并清理出相邻取入的侧视图上20行. 合并工作表不由客户端导入或嵌入PDF中. 重跑的一代产生字节-同义的PNG并显示.

<a name="compare-and-download"></a>

## 比较和下载

 在共享的详细说明、汽车服务和车队卡中,“Compare before/after”出现在每一类别中至少有一张照片。 对话框让用户独立选择相片,并肩查看相片,或者用可移动分页符来覆盖相片. 分出器与鼠标,触摸,以及单独的键盘可访问滑动器相配合. 图像完全合用而不裁剪;“并排”对于不同的观点更为可取。  在电话上, 图像会垂直地堆放在这个模式中。 “ 放大” 将选定的相片分开打开 。

“Download PNG ” 保存了2,000 px 宽的成分,并带有组织名称和标题。“一边走”会输出相邻的相片,而不论屏幕宽度如何;“滑行者”会保留分裂者的当前位置。 按钮和内部工作序细节不包含在图像中.  导出不创建公共链接或发布相片 。

允许查看工作顺序的用户,包括只读的用户,可以进行比较。 图像组成使用授权的 GET `/api/v1/media/maintenance/{maintenanceId}/photos/{photoId}/content?organizationId=...`:服务器检查组织和工作订单访问及相片所有权. 已存在的存储服务流到响应时没有缓存.  因此,出口不依赖于云存储 CORS. 临时图像 URL 在对子更改和对话框关闭时发布.

服务器测试照片发送(允许请求、他人的照片、无法进入或缺失的工作顺序、以及未经认证的用户)和浏览器选择对等方案,两种模式、PNG内容、鼠标/触摸/键盘操作、加载错误和重试、缩放、关闭和焦点返回都包括在内。 UI检查使用测试 API 响应. 不需要进行新的移徙比较。

## 检查一个认证的账户

运行 `scripts/maintenance/check-detailing-intake.js`  在使用开发工具的认证的 OpenCRM 标签中: 来源 → 片段 → 新的片段 。 打开详细的工作空间,将文件内容粘贴为新的片段,并按 Ctrl+Enter 键. 使用拥有所选组织的管理员账户;组织必须允许更改.
