# 订阅管理

[English](admin-subscriptions.md) | [Русский](admin-subscriptions.ru.md) | **简体中文**

> 本页为机器译稿。涉及部署、接口或数据变更时，请同时核对英文或俄文原文。

 这是一个可选模块,由 `PlatformPolicy:Commercial:Enabled`,默认为 `false`. 被禁用时,商业管理部分会被隐藏起来,不需要订阅即可使用客户关系管理系统. 安装所有者使模块能够使用,并配置价格、报价和试用条件。

<a name="organizations-and-access"></a>

## 组织和准入

PRO订阅属于一个组织.  没有主动订阅的明细和服务站组织继续免费的基本运营而未到期.  每个账户都有个人车辆;个人计划和以往模型的订阅仍为相容性。

网络管理员界面有一个单独的“组织”清单,包括没有付费订阅记录的自由组织。 访问要求 `Admin.Users.View`.  按名称/TIN和所有者/成员搜索服务器;每个页面包含最多25个组织。  在窄屏幕上使用卡片。“组织和订阅”打开相应的所有者标签。 桌面使用现有的组织列表. 存档,删除,不活跃的组织不显示为Free上的持续基本操作.

网络管理员“付款和订阅”部分从组织订阅开始。 免费不创建合成订阅记录,被排除在付费订阅统计之外.  卡片显示状态,名词,出处,历史;按状态,计划,出处的搜索和过滤仍然可用.

<a name="administrative-actions"></a>

## 行政行动

 一个管理员 `Admin.Billing.Manage` 订阅时间可延长1至366天,提供不付费的定期支付计划,或终止主动订阅。 需要一个理由; 扩展和取消验证表单打开时显示的名词. 审计日志存储动作、作者、理由和日期。 人工补助被贴上详细和服务站的标签。

Profileing和Service Station的定期演示赠款都隐藏在客户端中,并被服务器所禁止.  在PRO试验中使用带有奖金日的组织促销代码. 代码、术语、计划、情景和限制在编辑器中配置; `30days` 不是一个系统要求。 撤销先前发布的演示仍然得到支持。  当PRO过期或最后的演示被取消时,该组织在Free上继续基本运行并保存其历史.  未用带薪时间不自动恢复。

 以前的个人订阅和隐藏的"舰队"情景保留了他们的规则. 赠与和撤销旧的演示仍可供他们使用。 撤销演示只结束演示订阅;停止订阅结束所有对所选目标的活跃订阅. 这些行动不会重写付款。

<a name="plans-and-limits"></a>

## 计划和限度

System Free 由系统识别 `workspace.free.v1` 组合。  它被显示为免费和无限期的,不提供购买、促销赠款、残疾或删除。 其系统组、价格和可用性旗都受到保护。 技术 `DurationDays`  未设定自由进入期。

免费配额和能力是可以编辑的。 密码 `workspace.clients.limit` 和 `workspace.vehicles.limit` 任务不能被去除,但是其数值可以被改变. 车辆限制与计划表同步;在保存能力后,由编辑器重新加载. 网页编辑器在保存一个计划后保持开放,并忽略了对之前选择的计划的后期能力响应.  在装入成功之前, 能力不会被保存 。

方案选项确定实际价格、术语和能力。 明确确定以前的基地、示范和个人计划;保留其数据和支付条件。 免费被排除在组织宣传码计划选择之外。

<a name="existing-records"></a>

## 现有记录

已失效的商业模式隐藏其管理控制并省略了当前管理员回复中的商业细节.  它不删除历史计划、订阅、付款或审计记录。 遗产来源,例如: `paid`, `demo`, `manual`,以及 `unknown` 记录不自动重新分类。
