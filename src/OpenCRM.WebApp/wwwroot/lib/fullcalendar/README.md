# Локальная правка FullCalendar 6.1.20

В `index.global.min.js` метод `renderFillSegs` передаёт в `Xl` минимальную высоту 0 вместо `eventMinHeight`. Фон нерабочего времени, фоновые события и выделение должны точно соответствовать своим интервалам. Минимальная высота и расчёт расположения обычных карточек в `renderPositionedFgSegs` сохранены.

При обновлении библиотеки проверить, исправлено ли это поведение в новой версии, и при необходимости повторить правку. Регрессия: `node --test src/OpenCRM.Frontend/tests/calendarBackground.test.mjs`; дополнительно проверить в браузере короткий перерыв и кнопку переноса короткой записи.
