# Правила лаунчера административного приложения

- Соблюдай ограничения и совместимость целевых платформ.
- Не сохраняй локальные пути пользователя, адреса окружений, учётные данные или параметры сети в исходном коде.
- При изменении запуска или окна сохраняй существующую авторизацию и безопасную передачу аргументов.
- Проверяй изменения сборкой проекта и подходящими локальными сценариями.
