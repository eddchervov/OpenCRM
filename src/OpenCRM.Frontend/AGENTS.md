# Правила frontend

- Сначала проверь существующие общие компоненты и используй их вместо дублирования поведения и оформления.
- Сохраняй адаптивность, доступность, клавиатурное управление и светлую/тёмную темы.
- Проверяй права пользователя до показа доступного ему действия или перехода.
- Для даты и времени переиспользуй общие picker из пакета `packages/ui`; не добавляй нативные HTML-поля даты или времени.
- Следуй принятой структуре и стилю ближайшего пакета. Не меняй несвязанные клиентские сценарии.
